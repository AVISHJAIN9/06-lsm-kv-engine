# Contributing to LSM-Tree Key-Value Engine

Thank you for your interest in contributing to **LSM-Tree Key-Value Engine**! We welcome bug reports, design improvements, and performance enhancements.

## Code of Conduct
This project adheres to the [Contributor Covenant 2.1](CODE_OF_CONDUCT.md). By participating, you agree to honor its terms.

## Development Workflow
1. **Fork the Repository**: Create your personal fork on GitHub.
2. **Create a Feature Branch**:
   ```bash
   git checkout -b feature/your-feature-name
   ```
3. **Commit Guidelines**: Use clear semantic commit messages:
   - `feat:` new capabilities or architectural additions
   - `fix:` bug fixes or determinism patches
   - `docs:` documentation improvements or diagrams
   - `perf:` algorithmic optimizations or cache latency gains
4. **Submit a Pull Request**: Push your branch and open a PR against `main`. Provide a concise summary of changes and reference any relevant issue tickets.
