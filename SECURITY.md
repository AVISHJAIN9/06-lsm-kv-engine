# Security Policy

## Supported Versions
| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |
| < 0.1.0 | :x:                |

## Reporting a Vulnerability
If you discover a security vulnerability within **LSM-Tree Key-Value Engine**, please do **NOT** open a public issue.

Send a detailed report with reproduction steps to **avishjain412@gmail.com**. You will receive an acknowledgment within 48 hours. Security disclosures are addressed and patched prior to public notification.
